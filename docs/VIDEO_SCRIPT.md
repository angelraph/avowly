# Demo video script (about 2:30, hard limit under 3:00)

Produced from screen recordings at phone size, framed as a phone, with animated captions and an original synthesized music bed. Every screen is real PayPal sandbox activity on the live site (https://avowly.vercel.app), except the meetup QR screen, which was recorded on a local copy running the same code with sandbox keys. Real deals shown: the Oppo A58 sale (jz8gdc2k34f7), the HP laptop rental (d6r8tnmjta2m), the PayPal dispute PP-R-GVB-10196424, the judge demo deal (sjaz9ut96z6c), and the HP laptop listing verified with Log in with PayPal.

**Rules respected:** public on YouTube; shown at phone size; no copyrighted music; no third-party marketplace logos; no personal data on screen (full IMEI and handoff photos blurred).
